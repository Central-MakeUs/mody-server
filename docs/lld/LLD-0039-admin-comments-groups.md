## 1. 목적 / 배경

2026-11-21에 댓글이 앱에 공개됐고, 앱에는 댓글 신고 API(#286)도 생겼다. 하지만 관리 화면에서는 댓글을 볼 수도, 댓글 신고를 처리할 수도 없었다.
회원과 그룹 맥락도 여러 화면에 흩어져 있었다. 기존 Google 세션, 역할(VIEWER/OPERATOR/ADMIN), CSRF, 작업 이력(`admin_audit_log`)을 그대로 쓰고, 화면과 조회 API만 더한다.

## 2. 범위

| 기능 | 화면 | API |
| --- | --- | --- |
| 기록 댓글 보기 | 인증 피드 상세 | `GET /api/v1/admin/feed/{type}/{id}` 응답에 `comments` 추가 |
| 댓글 신고 처리 | 신고 처리 > 댓글 신고 | `GET /api/v1/admin/reports/comments`, `/comments/summary`, `POST /comments/{commentId}/hide`, `/dismiss` |
| 생년월일 · 소속 그룹 | 회원 목록, 인증 피드 카드, 그룹 구성원 | 회원 목록 `profiles`, 인증 피드 `authors` 추가 |
| 그룹 페이지 | `/admin/groups`, `/admin/groups?groupId=` | `GET /api/v1/admin/group-pages`, `/{groupId}` |

- 성별은 저장하는 컬럼이 없다(`member`, `social_account` 모두). 받으려면 앱 변경이 필요해서 이번 범위에서 뺐다.
- 그룹명 수정은 기존 그룹 관리(`/admin/challenges?view=groups`)에 남긴다. 그룹 페이지는 조회 전용이고, 그룹 관리로 가는 링크를 둔다.

## 3. 상세 설계

### 3.1 기록 댓글

- 식사·운동 기록 상세에 그 기록의 댓글을 작성 순으로 최대 500개 보여준다. 챌린지 인증에는 댓글이 없어서 빈 목록이다.
- 삭제된 댓글도 `deleted=true`로 포함한다. 신고 처리를 판단할 때 지워진 댓글도 봐야 하기 때문이다.
- 항목: 댓글 ID, 그룹(ID·이름), 작성자(탈퇴하면 `탈퇴한 회원`), 내용, `emojiId`, 작성 시각, 삭제 여부와 시각, 신고 수.
- 이모지만 있는 댓글(`content=""`, `emojiId`)은 화면에서 `:mody-<id>: (이모지)`로 보여준다. 본문 안의 토큰은 그대로 보여준다.

### 3.2 댓글 신고

- 기록 신고(LLD-0037 단계 2)와 같은 구조다. `comment_report`를 댓글 단위로 묶어 신고 수, 대기 수, 첫 신고·최근 신고 시각, 신고자 미리보기(5명)를 보여준다.
- 상태 필터: `PENDING`(대기 신고가 하나라도 있음), `RESOLVED`, `ALL`. 키셋 커서는 `(최근 신고 시각, 댓글 ID)`이다.
- 숨김(`hide`): 댓글을 삭제(soft delete)하고 대기 중인 신고를 `HIDDEN`으로 닫는다. 기록과 다른 댓글은 그대로 둔다. 이미 삭제된 댓글이어도 신고는 닫는다.
- 기각(`dismiss`): 댓글은 그대로 두고 대기 중인 신고를 `DISMISSED`로 닫는다.
- 대기 중인 신고가 없으면 404다. 처리자(`resolved_by`)에는 관리자 이메일을 남기고, POST 요청은 기존 인터셉터가 작업 이력에 기록한다. VIEWER는 처리할 수 없다(403).

### 3.3 생년월일 · 소속 그룹

- `AdminMemberProfiles`가 화면에 나온 회원(최대 500명)의 생년월일과 지금 참여 중인 그룹(`JOINED`, 그룹 활성)을 한 번에 읽는다. 목록 쿼리 자체는 바꾸지 않는다.
- 회원 목록 응답에는 `profiles`, 인증 피드 목록 응답에는 `authors`로 붙는다. 둘 다 회원 ID 문자열이 키다.
- 만 나이는 화면이 한국시간 오늘을 기준으로 계산한다.

### 3.4 그룹 페이지

- 목록: 활성 그룹을 만든 순(최신 먼저)으로 보여준다. 그룹명 부분 일치, 초대 코드(대소문자 무시), 그룹 ID로 검색한다. 참여 인원, 최근 7일 기록 수, 최근 기록 시각을 같이 준다.
- 상세
  - 기본 정보: 이름, 초대 코드, 만든 날, 기록 수, 최근 7일 기록 수, 댓글 수
  - 구성원(최대 200명): 그룹 표시 닉네임, 계정 닉네임, 생년월일, 참여 상태, 참여·나간 시각. 참여 중인 사람을 먼저 보여준다.
  - 주간 챌린지(최근 30개): 기간, 상태, 인증 수. 한국시간 오늘 기준으로 `CURRENT`, `PAST`, `UPCOMING`을 붙인다.
  - 최근 댓글 50개
  - 최근 기록: 인증 피드 API를 `groupId` 필터, 최근 1년으로 불러와 24장을 보여준다.

## 4. 테스트

- `AdminCommentReportServiceTest`: 댓글별 묶음, 페이지 커서, 집계, 숨김(그 댓글만 삭제), 기각, 대기 신고가 없을 때 404
- `AdminFeedServiceTest`: 상세의 댓글(삭제 포함, 신고 수, 이모지), 챌린지 인증은 빈 목록, 목록의 작성자 맥락
- `AdminMemberServiceTest`: 목록의 생년월일과 참여 그룹
- `AdminGroupPageServiceTest`: 이름·코드·ID 검색, 커서, 상세의 구성원·챌린지 구분·댓글
- `AdminPageControllerTest`: `/admin/groups`가 운영 화면으로 전달됨
